# ApexBuffer

Predictive input buffer for Geometry Dash (Geode).

You still press — the mod only **retimes** early clicks so they land clean.  
Polished in-game control panel with customizable colors (UI inspired by modern buffer mods).

## Platforms
- Windows
- Android (32 / 64)

## Controls
- **F9** — control panel (pause while open)
- **F6** — cycle stages
- Mobile: draggable **AF** button (opens panel)

## Stages
Stages control how far ahead inputs may be delayed. Stage 8 = off (raw input).

## Build
Push to `main` or run the GitHub Actions workflow. Download the **Build Output** artifact.
